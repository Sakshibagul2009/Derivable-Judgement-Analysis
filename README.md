# Derivable Judgement

## 📌 Project Overview

**Derivable Judgement** is a statistical analysis project developed using Python and Jupyter Notebook. The project focuses on applying statistical techniques to a dataset and deriving meaningful conclusions based on the results.

## 🎯 Objectives

- Understand and analyze the given dataset.
- Perform descriptive statistical analysis.
- Apply appropriate statistical tests.
- Measure relationships between variables.
- Interpret statistical results.
- Make data-driven conclusions based on statistical evidence.

## 🛠️ Tools & Libraries Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Statistics

## 📊 Statistical Analysis

The project covers statistical techniques such as:

- Descriptive Statistics
- Mean, Median and Standard Deviation
- Covariance
- Correlation
- Hypothesis Testing
- t-Test
- Chi-Square Test
- ANOVA
- Interpretation of p-values
- Null and Alternative Hypothesis

## 🔍 Methodology

1. Load the dataset.
2. Understand the variables and data types.
3. Perform data cleaning and preprocessing.
4. Calculate descriptive statistics.
5. Apply suitable statistical tests.
6. Analyze test results and p-values.
7. Accept or reject the null hypothesis where appropriate.
8. Interpret the findings and draw conclusions.

## 📈 Key Outcomes

The project demonstrates how statistical methods can be used to identify relationships, compare groups, test assumptions, and derive meaningful conclusions from data.

## 🚀 How to Run

1. Clone this repository.
2. Open `Derivable Judgement.ipynb` in Jupyter Notebook or Google Colab.
3. Install the required Python libraries.
4. Run the notebook cells sequentially.

## 📌 Conclusion

This project provides practical experience in statistical analysis and hypothesis testing using Python. It demonstrates how statistical evidence can be used to support meaningful and data-driven judgement.
